# DePrint for Mac — downloads

Release files only (the source is private). Download the latest DMG from
[Releases](https://github.com/Linyou/deprint-releases/releases/latest).

DePrint is free for 3 days, then $4.99 once. Requires an Apple Silicon Mac
with macOS 13 or later.

`latest.json` in each release is the signed update feed the app checks.
